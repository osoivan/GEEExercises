## Repository description

This repository contains practical exercises and examples for learning and applying **Google Earth Engine (GEE)** for geospatial analysis, remote sensing, environmental monitoring, and spatial data science.

The repository was designed for students, researchers, and professionals interested in cloud-based geospatial processing using satellite imagery and Earth observation datasets.

---

## Repository overview

The exercises include workflows related to:

- Google Earth Engine basics
- Satellite image visualization
- Raster processing
- Vegetation indices
- Land surface temperature
- Remote sensing applications
- Spatial analysis
- Environmental monitoring
- Data extraction and export
- Time-series analysis
- Geospatial visualization

The scripts are mainly developed using:

- **Google Earth Engine**
- **Python**
- **Jupyter Notebook**
- **JavaScript API**

To use these exercises you need:

- A Google Earth Engine account

## Getting started

Clone the repository:

```bash
git clone https://github.com/osoivan/GEEExercises.git
```

## Example workflow

Typical workflow:

```text
Load satellite imagery
→ Filter by date and area
→ Process raster data
→ Generate indices
→ Visualize results
→ Export outputs
```

---

## Important note

Some scripts may require significant processing time depending on:

- Spatial extent
- Temporal range
- Dataset resolution
- Number of images
- Internet connection
- Google Earth Engine server load

For large study areas, it is recommended to start testing using a smaller Area of Interest (AOI).
